TRITORC CALCULATORS

1. Save the ZIP to your computer and extract it (right-click > Extract All).
2. Double-click Tritorc_All_Calculators.html.
3. Use the buttons at the top right to switch between:
     - Fitment Checker (BTL series)
     - Torque Calculator
     - Tensioning Calculator

Each HTML file in this folder is fully self-contained: you can zip and
send just ONE of them and the nav bar buttons still work for the person
you send it to, because all three calculators are built into every file.
They only differ in which calculator opens first. Values you enter are kept while you switch between
calculators, until the page is closed or reloaded.

Tip: add #fitment, #torque or #tension to the end of the file address
to open a specific calculator directly.

An internet connection is only used to load fonts; the calculators
themselves work offline.
