# Tritorc Calculator Package

Standalone, self-contained HTML calculators for Tritorc bolting tools. No installation or server required — just open a file in a browser.

## Calculators

- **Tritorc_Bolt_Torquing_Calculator.html** — Torque calculator
- **Tritork_BTL_Fitment_Checker_R3.html** — Fitment checker (BTL series)
- **bolt_tensioning_calculator.html** — Tensioning calculator

## Usage

1. Download the repository (or just the single `.html` file you need).
2. Double-click the file to open it in your browser.
3. Use the buttons at the top right to switch between the Fitment Checker, Torque Calculator, and Tensioning Calculator.

Each HTML file is fully self-contained — all three calculators are built into every file, so you can send just one file and the nav bar buttons will still work for the recipient. The files only differ in which calculator opens first. Values entered are kept while switching between calculators until the page is closed or reloaded.

**Tip:** Add `#fitment`, `#torque`, or `#tension` to the end of the file address to open a specific calculator directly.

An internet connection is only used to load fonts; the calculators themselves work offline.
